# Loomnovel 织机

Loomnovel 是一个基于 Agent 和真实作者写作工作流的长篇小说创作平台，支持中文和英文。

这个仓库介绍 Loomnovel 怎么工作、怎么保护您的书稿，以及我们怎么开发和测试它。下面链接的详细文档是英文的。

[English](README.md)

## 我们对作者的承诺

1. **数据隐私**。未经您的授权和允许，我们（Loomnovel）不会阅读和处理您的数据，也不出售、不分享给任何人。您使用 AI 功能，即知晓这一步需要的文字会发给对应的模型服务商处理。
2. **书稿用途**。书稿只用来帮您写这本书。我们（Loomnovel）不会用您的书稿改进我们提供的服务。您使用 AI 服务时，各家服务商的 API 协议见[各家服务](docs/data-and-privacy.md#providers)。整本书随时可以导出，项目随时可以删除。
3. **安全**。每本书只有作者本人能读写。书稿存放在欧盟的服务器上，全程加密传输，每天加密备份到欧盟境内的异地存储。
4. **费用**。内测期间，模型费用全部由我们承担。每次 AI 调用花了多少钱当场可见，按服务商的公开价计算，不加倍率。

## 和直接用 Codex + skills 或网页版相比

- **专为写作打造的工作台和工作流**。从排纲、起草、审稿到润色都在一个地方完成，每一次产出都留有版本，随时可以退回。我们精心编排的记忆会记下您的写作习惯和偏好，下次照着来。您也可以随时停下来亲手改正文，不必在十几个网页和工具之间来回切换。
- **不同模型灵活调用**。不同的基础模型在写作、编辑、润色上各有所长。我们按工序调用不同的模型，用合适的成本拿到最好的质量。
- **更适合写作的上下文编排**。我们直接通过 API 调用模型，避开编程 Agent 那套带工具说明的系统提示词，也不用为写代码专门调过的模型来写小说，这两样都会拉低文字质量。每个模型能有效关注的上下文长度不同，我们按它的上限决定喂多少资料；写作和编辑用的提示词，也按每个模型的能力分别打磨。
